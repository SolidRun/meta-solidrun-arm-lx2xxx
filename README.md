# Yocto BSP Layer for SolidRun LX2160A & LX2162A based Products

This is the SolidRun Yocto BSP Layer for NXP LX2160A & LX2162A Landing Page. Specific releases are organised in branches below:

- [scarthgap](https://github.com/SolidRun/meta-solidrun-arm-lx2xxx/tree/scarthgap):

  Based on NXP QorIQ LS-6.6.52-2.2.0 Release.

  This version is production-ready and actively supported with new features and fixes.

- [kirkstone](https://github.com/SolidRun/meta-solidrun-arm-lx2xxx/tree/kirkstone):

  Based on NXP QorIQ LS-5.15.71-2.2.0 Release.

  This version is legacy and maintained with critical bug fixes only.
